# Are You Desi Enough? — A Bollywood Quiz

A Jeopardy-style Bollywood quiz for a room full of friends. One host runs it on
a laptop or TV, and everyone else shouts, buzzes and argues.

**Play it here:** https://kavyaj.github.io/bollywood-quiz/

There's nothing to install and no sign-up. Open the link and the first board is
ready.

---

## What you need

- **A big screen.** A laptop plugged into a TV is ideal. The quiz is designed to
  be read from across a room, so it doesn't work well on phones.
- **One host.** The host holds the keyboard, reads the questions and decides
  who's right. The host can play along but can't win.
- **A buzzer.** Any free buzzer app that shows who buzzed first works. We used https://www.multibuzz.app/ for our session.
- **Paper and a pen for scores.** The quiz shows questions and answers. It
  doesn't keep score.

Press **F11** to go fullscreen before you start.

---

## How to play

### The boards

There are **three boards**. Each has **5 categories** with **5 squares**, worth
**10, 20, 30, 40 and 50 points**. Higher points mean harder questions.

Each board sits on top of a **hidden photo**. Every time a square is played, its
tile lifts and a bit more of the photo shows through.

### A turn

1. **Pick a square.** The player who got the last question right picks the next
   square. For the first pick, the host chooses someone.
2. **The host opens it.** Everyone sees the question at the same time.
3. **Buzz to answer.** The fastest buzzer gets the first guess.
4. **Right answer:** that player scores the square's points.
5. **Wrong answer:** the question passes to the next-fastest buzzer. Each
   player gets one guess per question.
6. **Nobody gets it:** the host reveals the answer, no one scores, and the tile
   still lifts.
7. **The host reveals the answer** so the whole room can see it, then goes back
   to the board. The tile lifts.

### The hidden photo

At any point during a board, a player can use their buzz to **guess the hidden
photo** instead of answering the question. A right guess earns a **bonus of 100
points**. A wrong guess costs **50 points**, and that player can't guess the
photo again on that board. When all 25 squares are gone, the host lifts
whatever's left so everyone can see the photo.

### Judging

The host has the final say. Near misses ("Om Shanti" for *Om Shanti Om*) are
the host's call, so agree before you start how strict to be. For **साल क्या था**
it's all three in the right order or nothing.

| --- | --- |

## Host keys

Press **H** at any time to see these keys on screen. You can also use the
mouse: click a square to open it, then use the on-screen buttons.

### On the board

| Key | Does |
| --- | --- |
| Arrow keys | Move the highlight |
| Enter / Space / click | Open the square |
| U | Undo the last lift |
| 1 / 2 / 3 | Switch board |
| Shift + Enter | Lift all remaining tiles (end-of-board reveal) |
| S | Save a backup file of the game |
| L | Load a backup file |
| Shift + N | New game: puts every tile back (asks first) |
| H | Show or hide the key list |

### On a question

| Key | Does |
| --- | --- |
| Space / Enter / → | Show the next clue, then the answer |
| ← | Step back one clue |
| R | Replay the audio clip |
| Backspace / Esc / ✕ | Back to the board without lifting the tile |

### On an answer

| Key | Does |
| --- | --- |
| Space / Enter / Back to board button | Back to the board, and the tile lifts |
| ← | Hide the answer again |
| Backspace / Esc | Back to the board without lifting the tile |

**Tips**

- Use **Backspace** to back out. Esc can also exit fullscreen.
- Use plain **1 / 2 / 3** to switch boards. Browsers often keep Ctrl + 1/2/3
  for switching tabs.
- A stray click on a question screen does nothing, so you can't reveal an
  answer by accident.
- Opening a square that's already lifted shows it again without changing
  anything.

## Your game is yours

Every game is saved **only in your own browser**, on your own device. Nothing is
sent anywhere, so people playing at the same time in different places never
affect each other's boards.

- **Close the tab by accident?** Open the quiz again in the same browser and
  it picks up where you left off.
- **Coming back for a fresh game?** Press **Shift + N**, then **Enter**, to
  reset every board.
- **Switching laptops mid-game?** Press **S** to save a backup file, move it to
  the other laptop, open the quiz there and press **L** to load it.
- Private or incognito windows don't keep your game after you close them, and
  clearing your browser data erases it.
